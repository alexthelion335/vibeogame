# Godot Project Skeleton

This directory contains the Phase B Godot shell for Chicken Potato FPS.

## Included

- `project.godot` with input map and autoload setup
- UI and world placeholder scenes for the main menu, gameplay, HUD, pause, inventory, shop, death screen, and touch controls
- GDScript stubs for the future C++ GDExtension integration point
- A placeholder `.gdextension` manifest for the eventual native library

## Next Phase

Phase C will replace the placeholder snapshot/input dictionaries with the actual C++ `GameState`, `InputState`, and `RenderSnapshot` bindings.
