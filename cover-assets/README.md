# Chicken Potato FPS SteamGridDB artwork

Ready-to-upload PNGs are provided alongside editable SVG source files. The art follows the Android launcher icon's warm orange palette, red comb, white chicken head, golden beak, and potato-colored body.

## Assets

| Files | SteamGridDB use | Dimensions |
| --- | --- | --- |
| `cover-01.png`, `cover-02.png` | Grid / vertical cover | 600 × 900 |
| `hero-01.png`, `hero-02.png` | Hero | 1920 × 620 |
| `background-01.png`, `background-02.png` | Profile background | 1920 × 1080 |
| `icon-01.png`, `icon-02.png` | Icon | 512 × 512 |

The SVG files with matching names are the editable vector sources. PNGs are rendered from those sources with rsvg-convert. The backgrounds are text-free so Steam can place interface elements over them.

## Art direction

Original vector artwork inspired by `android/icon/chicken_potato_icon.svg`: a bold, playful chicken-and-potato shooter character, sunset orange sky, red comb, cream feathers, and earthy browns. Covers and heroes carry the “CHICKEN POTATO FPS” title; backgrounds omit lettering for legibility behind UI.
