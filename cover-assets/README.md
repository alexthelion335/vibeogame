# Chicken Potato FPS SteamGridDB artwork

Ready-to-upload PNGs are provided alongside editable SVG source files. The art follows the Android launcher icon's warm orange palette, red comb, white chicken head, golden beak, and potato-colored body.

## Assets

| Files | SteamGridDB use | Dimensions |
| --- | --- | --- |
| `cover-01.png`, `cover-02.png` | Grid / vertical cover | 600 × 900 |
| `hero-01.png`, `hero-02.png` | Hero | 3840 × 1240 |
| `background-01.png`, `background-02.png` | Background | 3840 × 1240 |
| `capsule.png` | Capsule | 920 × 430 |
| `logo.png` | Logo (transparent PNG) | 1600 × 600 |
| `icon-01.png`, `icon-02.png` | Icon | 512 × 512 |

Each asset has an editable SVG source with the matching name. The logo PNG has an alpha channel and transparent pixels outside the lettering. The backgrounds are text-free so Steam can place interface elements over them.

## Art direction

Original vector artwork inspired by `android/icon/chicken_potato_icon.svg`: a bold, playful chicken-and-potato shooter character, sunset orange sky, red comb, cream feathers, and earthy browns. Covers, heroes, capsules, and the logo use the “CHICKEN POTATO FPS” title; backgrounds omit lettering for legibility behind UI.
